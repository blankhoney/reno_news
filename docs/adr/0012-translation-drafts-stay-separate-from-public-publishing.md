# Translation Drafts Stay Separate From Public Publishing

Milestone 3 translation output is stored as a policy-gated draft, not as reader-facing published content. Translation storage must remain separate from public display, reader pages, search indexing, and digest generation.

This keeps the rights boundary explicit. Source Policy and Rights Policy may allow private translation, public excerpt translation, or public full translation, but Issue 008 only creates the worker-side translation draft foundation. A later publishing issue must decide whether any draft becomes visible to readers.

Issue 008 should therefore add versioned translation output, model-call logging, policy prefiltering, and deterministic fake-adapter tests without adding reader UI, search, digest generation, or live API-key requirements.
