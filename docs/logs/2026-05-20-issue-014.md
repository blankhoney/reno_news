# 2026-05-20 Issue 014 Log

## Objective

Add the next Milestone 5 admin UI slice: a read-only failure queue for recent ingest, extraction, and model-processing failures.

## Research

- Re-read Milestone 5 scope in `docs/CODEX_MASTER_PLAN.md`.
- Re-read local domain language around Admin, Admin Debug Surface, Ingest Attempt, Extraction Attempt, and Model Call.
- Queried current Fastify docs through Context7 for v5 route validation and full JSON Schema requirements.
- Checked existing database migrations and worker writers for `source_ingest_attempts`, `raw_entry_extraction_attempts`, and `model_calls`.

## Design Decision

Use existing attempt and model-call logs as the failure queue source. Issue 014 should build a read-only projection and should not add retry, acknowledgement, resolution state, or a new failure queue table.
