# 2026-05-20 Issue 006 Log

## Objective

Implement `docs/CODEX_MASTER_PLAN.md` Issue 006: full-text extraction foundation.

## Research

- Queried current Trafilatura documentation for URL/HTML extraction, metadata extraction, structured output, and no-result handling.
- Queried current HTTPX documentation for timeout, redirect, status, and request-error handling.
- Re-read local deep research notes for the selected fetch/extract path: HTTPX plus Trafilatura as the primary path, with browser automation and commercial fallbacks deferred.

## Design Decision

Keep extraction attempts and extraction results separate from `raw_entries`. The raw entry remains feed metadata; extraction output becomes private worker output for later normalization and evaluation.

## Implementation Notes

- Added Issue 006 planning document.
- Added ADR 0010 for extraction result storage boundary.
- Updated domain language with Extraction Attempt, Extraction Result, and Extraction Confidence.
- Added `raw_entry_extraction_attempts` and `raw_entry_extractions`.
- Added worker extraction path using HTTPX and Trafilatura.
- Added strict policy gate requiring `save_level = 'full_text'` and full-text-compatible rights policy.
- Added attempt recording for policy skip, network/status failure, no-text parse failure, and success.
- Added extraction result storage with extractor identity, final URL, optional metadata, text length, and bounded confidence.
- Added Dramatiq actor for extracting one raw entry.
