# 2026-05-20 Issue 024 Log

## Objective

Plan the next Milestone 7 slice: a local Disk Usage Guard foundation.

## Research

- Checked Docker `json-file` logging driver documentation for `max-size` and `max-file` rotation options.
- Checked Docker logging configuration documentation for default `json-file` behavior and log option boundaries.
- Checked Docker Compose service documentation for service-level `logging` configuration.
- Checked Docker `system df` documentation for Docker daemon disk usage inspection.

## Design Decision

Issue 024 should add local, non-destructive disk guardrails: bounded Compose log retention and a read-only disk usage check. The check may report Docker daemon usage and local backup artifact size, but it must not prune Docker resources, remove volumes, delete backups, call remote monitoring, send alerts, deploy, push images, or mutate production state.

## Implementation Notes

- Added Disk Usage Guard and Log Retention Policy terminology to `CONTEXT.md`.
- Added ADR 0028 for local log rotation and read-only disk checks.
