# 2026-05-20 Issue 021 Log

## Objective

Plan the next Milestone 6 slice: Admin Feedback Review that can dismiss invalid feedback from the Quality Feedback Penalty without mutating item lifecycle.

## Research

- Re-read Issue 017 feedback capture, Issue 020 feedback penalty, ADR 0021, ADR 0024, and current feedback API/admin page code.
- Checked Next.js 16.2.2 guidance for Server Actions with forms, `FormData`, `revalidatePath`, and `redirect`.
- Checked Fastify v5 guidance that params/body schemas must use full JSON Schema.

## Design Decision

Issue 021 should store constrained review state on `reader_feedback` and keep the workflow event-local. `dismissed` feedback should be excluded from Quality Feedback Penalty. Feedback Review must not hide/restore content, change lifecycle, personalize ranking, add Admin identity, or create a moderation queue.
