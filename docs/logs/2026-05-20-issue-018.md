## Design Decision

Start Related Items as a small reader-detail affordance selected from the same policy-visible PostgreSQL projection used by reader listings, detail pages, and search. Related Items may use shared board, shared source, recency, and reader-safe PostgreSQL full-text rank, but must not consume feedback, personal saved/read-later state, digest membership, private extraction text, translation drafts, semantic vectors, or external search services.
