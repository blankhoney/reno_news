## Design Decision

Start feedback as append-only, item-scoped server-side events. Feedback should be constrained by Feedback Type and accepted only for reader-visible items. Issue 017 should not create reader accounts, backend saved/read-later sync, automatic moderation, ranking mutation, digest generation, semantic/vector search, external search services, browser automation, or non-RSS adapters.
