## Design Decision

Start with reader-safe PostgreSQL search over the existing reader projection. Issue 016 should not search private extraction text or translation draft full text, and should not add Meilisearch, OpenSearch, `pg_trgm`, `zhparser`, semantic search, feedback logic, or digest generation.
