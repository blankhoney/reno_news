# 2026-05-20 Issue 022 Log

## Objective

Plan the first Milestone 7 slice: local PostgreSQL Backup Snapshot and Restore Drill foundation.

## Research

- Checked PostgreSQL 18 `pg_dump` documentation for custom-format archives suitable for `pg_restore`.
- Checked PostgreSQL `pg_restore` documentation for archive restore behavior, `--exit-on-error`, and restore safety warnings.
- Checked Docker Compose `exec` documentation for non-interactive command execution with `-T`.

## Design Decision

Issue 022 should use a manually invoked PostgreSQL custom-format logical dump and a disposable restore target. This gives the project a concrete restore proof before adding production scheduling, remote object storage, WAL archiving, point-in-time recovery, monitoring, alerting, or release automation.
